# Monochrome Figures for the Vestnik Manuscript

## Goal

Replace the six stylistically inconsistent color figures in
`phd.paper/VestnikPaper/main_for_vestnik.tex` with exactly four reproducible
black-and-white figures. The new sequence must explain the method from input to
evaluation and remain legible in the printed version of *Moscow University
Computational Mathematics and Cybernetics*.

The figures must support the manuscript's claims rather than add decorative
material. No curve or metric may be reconstructed approximately from a raster
image.

## Figure Set

### Figure 1: Two-stage retrieval pipeline

Show the complete method in two lanes:

- offline: document \(d\) to \(F_\theta(d)\) and \(K(d)\), then to the index;
- online: query \(q\) to primary retrieval by \(s_0\), candidate set \(C_p\),
  lexical score \(s_{\mathrm{qlex}}\), combined score \(s_\gamma\), and final
  \(top_k\).

The diagram must use the notation already defined in the manuscript. It
replaces `top-k-top-p.png` and makes the role of stored keywords explicit
without showing a large sample paragraph.

### Figure 2: Worked example of \(s_{\mathrm{qlex}}\)

Use the neutral technical example already present in the problem statement:

- query: which Git command creates a branch and immediately switches to it;
- relevant passage: `git switch -c new-branch` creates a branch and switches
  the working copy to it.

Show query-token positions, matching passage tokens, occurrence counts, and the
contribution of each position to the numerator and denominator of
\(s_{\mathrm{qlex}}\). The figure must agree exactly with the formula in the
paper and replace `sample-hunger-games.png`.

### Figure 3: Training the score coefficients

Do not redraw the old loss curves because their original experiment log has
not been established as the source of the existing raster image.

Instead, show the mathematically verifiable training path:

1. batch matrices \(S_0\in\mathbb{R}^{N\times N}\) and
   \(S_{\mathrm{qlex}}\in\mathbb{R}^{N\times N}\);
2. \(S_\gamma=\gamma_0S_0+\gamma_{\mathrm{qlex}}S_{\mathrm{qlex}}\);
3. diagonal positive pairs;
4. row-wise cross-entropy;
5. gradients with respect to \(\gamma_0\) and
   \(\gamma_{\mathrm{qlex}}\).

This replaces `Loss-BiGamma-vs-Gamma.png` with a figure that is derived directly
from the equations and implementation.

### Figure 4: HitRate@2 across six configurations

Use a horizontal dot plot with six rows:

- multilingual-E5-small on \(D_u\) and \(D_v\);
- multilingual-E5-base on \(D_u\) and \(D_v\);
- multilingual-E5-large on \(D_u\) and \(D_v\).

Plot dense retrieval \(R_e\), hybrid retrieval \(R_h\), and the proposed
reranker \(R_\gamma\) using different marker shapes. The values must be read
from `tables/hitrate-small.tex`, `tables/hitrate-base.tex`, and
`tables/hitrate-large.tex`. The figure must expose both absolute HitRate@2 and
the distance between methods. BM25 remains in the result tables and is omitted
from the figure to keep the comparison focused and legible.

## Visual System

All four figures use one plotting system and one style:

- white background and black foreground only;
- no semantic distinction encoded only through color;
- solid, dashed, and dotted lines plus distinct marker shapes;
- Russian labels, with mathematical symbols matching the manuscript;
- 8--9 pt minimum text at final printed width;
- dimensions chosen for the official `cmcherald` text width of 170 mm;
- restrained boxes and arrows, without decorative shadows or gradients;
- vector PDF and EPS outputs, plus a 600 dpi grayscale PNG fallback.

The figures will be generated by one Python entry point using Matplotlib so
font sizes, line widths, margins, and export settings cannot drift between
files. Figure 4 will read its metric values directly from the three LaTeX
result tables; the drawing code must not contain a duplicated copy of those
numbers.

## Manuscript Integration

The implementation will:

1. replace the six active `\includegraphics` calls with four new files;
2. remove or rewrite paragraphs that discuss discarded UMAP and trace plots;
3. replace the Hunger Games explanation with the Git example;
4. explain Figure 3 as the batch-matrix training computation, not as an
   empirical convergence comparison;
5. place Figure 4 after the result tables;
6. update captions, labels, and cross-references;
7. keep the article at no more than 15 pages and exactly four numbered
   illustrations.

Migration of the full manuscript to the official `cmcherald` class is a
separate formatting task. The new assets are nevertheless designed for that
class and must be verified at its final text width.

## Verification

The work is accepted only when:

- the generation script reproduces all four output files from repository data;
- the plotted HitRate@2 values exactly match the three source tables;
- raster fallbacks are true grayscale images, not RGB images that merely look
  gray;
- all text remains readable in a rendered manuscript at 100% scale;
- the manuscript has exactly four active numbered figures;
- every figure is referenced in the text and every reference resolves;
- LaTeX reports no missing files, undefined references, or overfull boxes
  caused by the new figures;
- rendered pages show no clipped labels, collisions, or ambiguous line styles.

## Out of Scope

- changing the experimental results;
- inventing confidence intervals when repeated-run data are unavailable;
- recreating missing raw curves by tracing existing PNG files;
- redesigning result tables;
- completing the broader `cmcherald` migration in the same change.
